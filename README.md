### Постановка задачи

В ходе выполнения работы необходимо было реализовать следующий функционал:

1. **Парсинг TBX:** Извлечение терминологических пар (EN-RU), частей речи и определений из XML-файла с корректной обработкой пространства имён `xml:lang`.
2. **Парсинг TMX:** Извлечение параллельных сегментов (оригинал и перевод) и формирование колонки с предыдущим предложением для поддержки контекстного поиска.
3. **Fuzzy Match:** Разработка алгоритма нечёткого поиска на основе метрик Левенштейна и Token Sort Ratio (с порогом отсечения 75%). Реализация логики распознавания контекстных совпадений (ICE 101%).
4. **Интеграция глоссария:** Автоматическая подстановка переводных эквивалентов в исходный текст с защитой от частичных совпадений (по границам слов) и приоритетом длинных терминов.
5. **Экспорт данных:** Сохранение глоссария и отчёта о совпадениях в форматы CSV, совместимые с импортом в Smartcat.
